# Devkit

Development kit for the repositories of the Sic programming language.
It holds what they share to develop, check and review their content: the modules of their flakes, their workflows, and the agents that work in them.

## Usage

The skills of [`skills/`](skills) explain how to use devkit, to agents and to humans alike: [`devkit`](skills/devkit/SKILL.md) how to set it up in a repository, and one skill per module what the module offers and how to use it.

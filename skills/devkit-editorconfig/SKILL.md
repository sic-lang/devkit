# editorconfig

The `editorconfig` module checks every file in the repository with [editorconfig-checker](https://github.com/editorconfig-checker/editorconfig-checker).
It generates the [EditorConfig](https://editorconfig.org) file, `.editorconfig`, with the `files` module, so that editors follow the same rules as the check.

## Set it up

1. Import `inputs.devkit.flakeModules.editorconfig`, as the `devkit` skill shows.
2. Run `nix run .#setup-files`, which writes `.editorconfig`, and commit the file.
3. Run `nix run .#check-editorconfig` and `nix run .#check-files`.

## The configuration

`.editorconfig` holds the rules, and the reason for each exception.
It sets no maximum line length for YAML files, because the `yaml` module checks it.
So a repository with YAML files also uses the `yaml` module, as the `devkit-yaml` skill shows.

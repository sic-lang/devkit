# yaml

The `yaml` module checks every YAML file in the repository with `yamllint --strict`.
It generates yamllint's configuration, `.yamllint.yaml`, with the `files` module.

## Set it up

1. Import `inputs.devkit.flakeModules.yaml`, as the `devkit` skill shows.
2. Run `nix run .#setup-files`, which writes `.yamllint.yaml`, and commit the file.
3. Run `nix run .#check-yamllint` and `nix run .#check-files`.

## The configuration

`.yamllint.yaml` holds the rules: yamllint's default, with the reason for each change.

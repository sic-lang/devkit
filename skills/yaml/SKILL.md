# yaml

The `yaml` module checks the repository's YAML files, every regular `*.yaml` and `*.yml` file that Git tracks, with `yamllint --strict`.
It generates yamllint's configuration, `.yamllint.yaml`, with the `files` module.

## Set it up

1. Import `inputs.devkit.flakeModules.yaml`, as the `devkit:adopt` skill shows.
2. Run `nix run .#setup-files`, which writes `.yamllint.yaml`, and commit the file.
3. Run `nix run .#check-yamllint` and `nix run .#check-files`.

## The configuration

`.yamllint.yaml` holds the rules: yamllint's default, with the changes whose reasons the module's [source](https://github.com/sic-lang/devkit/blob/main/sources/modules/yaml/default.nix) gives.

## Add the repository's settings

The option `devkit.yaml.settings` holds the repository's own [yamllint configuration](https://yamllint.readthedocs.io/en/stable/configuration.html), which the module writes together with its own.
A setting that the module also sets to a different value fails the evaluation of the flake.
This example ignores a directory:

```nix
perSystem.devkit.yaml.settings.ignore = "vendor/";
```

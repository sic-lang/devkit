# direnv

The `direnv` module generates the repository's `.envrc` with the `files` module.
From that file, [direnv](https://direnv.net) loads the development shell of the repository's flake, which the `devkit-commands` skill describes.
`.envrc` declares itself a Bash script, so that the `shell` module's ShellCheck check accepts it.

## Set it up

These steps set up the module in a repository:

1. Import `inputs.devkit.flakeModules.direnv`, as the `devkit` skill shows.
2. Run `nix run .#setup-files`, which writes `.envrc`, and commit the file.
3. Run `nix run .#check-files`.

Each contributor who uses direnv then sets it up as [its documentation](https://direnv.net/#getting-started) says.
